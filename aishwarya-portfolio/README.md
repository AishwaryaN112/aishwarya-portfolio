# Aishwarya N — Portfolio

Midnight Cyber Developer theme. A static HTML portfolio with no build dependencies.

## Preview
Open `index.html` in your browser.

## Update later
Edit the corresponding section in `index.html` (Projects, Training & ongoing learning, Skills, Contact), save and commit changes to GitHub. If Netlify is connected to the repository, it can automatically redeploy.

## Before publishing
- Add your professional contact email when ready.
- Confirm all education and project descriptions.
- Add project links only when real repositories/demos exist.
- NPTEL exam is pending; do not list as certified until results confirm it.
- Confirm exact NSDC credential wording once the certificate is retrieved.
- After choosing a permanent domain, add canonical URL, sitemap and Search Console verification.
